# Интерактивный макет BrightnessTray

Открыть `index.html` в браузере. Установка и сервер не нужны.

Данные: снимок реальных мониторов 10.11.2026 через MonitorWorker (только Scan, без Write).
- AF24H1: аппаратная яркость 89%, логическая 100%; кривая 18 / 36 / 54 / 71 / 89.
- Acer VG220Q: аппаратная яркость 94%, логическая 88%; кривая 33 / 52 / 72 / 88 / 100.
- Сохранённые настройки: синхронизация включена, быстрый режим 600 мс, аппаратный шаг 5%, колесо 5%. Подписи макета на русском; установленное приложение использует английский.

Синхронизация соответствует текущей логике приложения: общий логический уровень с индивидуальными калибровочными кривыми. При включении значения не скачут; первое движение общего ползунка выравнивает логические уровни. Ранее предложенное сохранение разницы отменено в пользу фактической логики приложения.

Работают общий и отдельные ползунки, колесо над иконкой (Ctrl — 1%), скрытие панели, светлая тема, настройки, сброс. Проверка мониторов имитируется по сохранённому снимку. Все изменения локальны в памяти макета и не затрагивают оборудование или settings.ini.

Солнышко — SVG-геометрия; лучи поворачиваются через requestAnimationFrame, центр неподвижен. Цикл останавливается в покое. Учитывается prefers-reduced-motion. Нет кадров, внешних ресурсов или сетевых запросов.

Проверено в Chrome: общий уровень 60/60, независимый 60/35, смена настроек, колесо, проверка мониторов, отсутствие ошибок JavaScript и переполнения при 320 px.

preview.png — статичный обзор. Файлы 01–04 — предыдущие исследования, актуальный макет — index.html.

## Перенастройка калибровки
Настройки → Настроить: выбор эталона, общий максимум, минимум, середина, 25%, 75%, итоговая таблица. Ползунки ограничены соседними точками, чтобы кривая оставалась возрастающей. Отмена отбрасывает черновик; сохранение применяет его к расчётам аппаратной яркости в макете. Сброс восстанавливает исходные кривые. Значения сохраняются только до перезагрузки страницы, settings.ini не меняется.
Проверены сохранение 89→85%, отмена, сброс, отсутствие ошибок JavaScript и переполнений на 320/550/1000 px.

## Поведение окон
Основная панель привязана к иконке и открывается над ней. Клик снаружи, потеря фокуса и Escape закрывают попап. Повторное открытие показывает яркость. Настройки — страница попапа. Калибровка — отдельный модальный dialog браузера, демонстрирующий отдельное окно будущего Win32-приложения; закрытие, Escape и отмена отбрасывают черновик и возвращают настройки. Настоящие окна ОС и системный трей HTML не создаёт. Проверены открытие/закрытие, сохранение/отмена и ширины 320/550/1000 px.


## Язык
Настройки → Язык интерфейса: Русский / English. Переводятся панель, настройки, подсказки и шаги калибровки. Выбор сохраняется в localStorage браузера отдельно от установленного приложения. Проверены переключение в обе стороны, мастер, перезагрузка и ширина 320 px.
