# BrightnessTray v0.2.0

Compact native brightness controls for Windows 10 (1809+) and Windows 11 x64.

- Tray popup with a compact link button, inline settings, and one shared slider for linked monitors.
- Separate target thumb and confirmed blue brightness line. Fractional drawing and adaptive interpolation follow the measured acknowledgement cadence without sending extra DDC commands.
- Procedural sun animation with continuous rotation, input retriggering, and a soft stop. No sprite sheets; Windows animation preferences are respected.
- Antialiased vector controls and DPI-sized tray icons with improved visibility at small sizes.
- Active-only frame pacing and reusable paint buffers reduce repeated drawing allocations.
- Popup positioning accounts for the hidden notification-icon flyout. Wheel adjustments no longer create a second brightness popup.
- Compact calibration window, live English/Russian language menu, scrollable settings on short work areas, and keyboard focus indicators with automatic scrolling to focused controls.
- Expanded tests cover slow acknowledgements, native popup behavior, failure cleanup, keyboard navigation, short settings windows, and partial wheel deltas. Code and UI changes received separate review.

## Downloads

- **BrightnessTray-0.2.0-Setup-x64.exe** — per-user installer and uninstaller.
- **BrightnessTray-0.2.0-Portable-x64.zip** — extract and run.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

Enable DDC/CI in the monitor menu. Exit the normal application before installing or upgrading. Existing preferences and calibration profiles are preserved. Binaries are unsigned.

The blue line reflects acknowledged values, not measured physical luminance. Device quantization, irregular DDC response times, and the first unknown response interval can still affect perceived smoothness. Physical DPI changes, DWM presentation timing, and all Windows shell arrangements were not exhaustively tested. Visual matching does not replace a colorimeter; HDR and GPU gamma are not modified.
