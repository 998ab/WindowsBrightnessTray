# BrightnessTray v0.2.1

Bug fixes for synchronized brightness and calibration on Windows 10 (1809+) and Windows 11 x64.

- Keep an error visible when only some linked monitors accept a brightness change. A later successful monitor no longer hides an earlier failure; a successful retry clears it.
- Reconcile the shared slider with restored brightness after calibration, including values changed externally before calibration.
- Preserve the hardware destination when resetting calibration during a transition, and show the target in the new calibration scale.
- Preserve the last valid monitor state and write backend after failed or invalid brightness reads. Invalid high-level replies can fall back to a valid VCP brightness reply.
- Add regression coverage for partial failures, retries, restoration, calibration reset during a transition, and malformed DDC/CI replies.

## Downloads

- **BrightnessTray-0.2.1-Setup-x64.exe** — per-user installer and uninstaller.
- **BrightnessTray-0.2.1-Portable-x64.zip** — extract and run `BrightnessTray.exe`.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

Exit BrightnessTray before upgrading. Existing preferences and calibration profiles are preserved. Enable DDC/CI in the monitor menu. Binaries are unsigned.

Automated tests use virtual monitors and simulated API failures; physical monitor and driver behavior varies.
