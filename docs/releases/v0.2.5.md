# BrightnessTray v0.2.5

A quieter Windows interface, with the same compact footprint.

- Use neutral light and dark surfaces with a restrained blue accent and clearer visual hierarchy.
- Group monitor rows and response/wheel preferences instead of presenting every control as an independent bordered rectangle.
- Distinguish selected preferences from primary actions using subtle surfaces and a short selection indicator.
- Replace the large calibration preference button with a compact switch and an explicit on/off caption.
- Refine slider thumbs, icon hover feedback, language selection, button focus outlines, and primary-action press feedback.
- Prefer Segoe UI Variable Text when installed, with Segoe UI as the fallback. Body and caption sizes are retained.
- Preserve the 320 × 250 DIP linked two-monitor panel and 320 × 348 DIP Settings window, plus the existing high-DPI scrolling and responsive calibration layout.
- Refresh README images and GIFs using the actual native demo interface.

The design was audited using UI UX Designer and follows the user-selected quiet Windows 11 direction. Hardware brightness control and saved settings retain their existing behavior.
