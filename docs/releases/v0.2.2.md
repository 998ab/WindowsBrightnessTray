# BrightnessTray v0.2.2

Fixes for the tray, wheel controls, calibrated maximum brightness, and wake recovery.

- Replace the executable and installer icon's old logo with the current sun at nine sizes, from 16 to 256 pixels.
- Rotate the tray sun only for brightness wheel input. Hovering, dragging sliders, presets, and calibration acknowledgements no longer start it.
- Wheel up increases brightness and wheel down decreases it over native sliders, matching the tray. The configured step, Ctrl precision, and partial wheel deltas are supported.
- Add **Settings → Apply saved calibration**. Turn it off to reach hardware 100%, then back on to use the saved matched range. Curves, current hardware brightness, and in-flight hardware destinations are preserved.
- Restore brightness after system sleep or display power-off. Re-enumeration and up to five attempts accommodate monitors that take time to expose DDC/CI. New brightness input cancels stale recovery. Sleep during calibration restores original levels rather than temporary matching samples.
- Extend regression tests for mode switching, native wheel input, sleep, display power events, failed recovery, and user input during recovery.
