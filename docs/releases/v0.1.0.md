# BrightnessTray v0.1.0

First public release for Windows 10 (1809+) and Windows 11 x64.

- Native Win32 tray app with a small memory footprint; no Electron, WebView, .NET, telemetry, or application network access.
- English/Russian UI with automatic initial language and a persistent live language switch.
- Per-display brightness, calibrated synchronization, tray wheel control, and presets.
- Three response modes: Instant, Quick, and Smoother.
- Five-point visual matching with full-edge samples placed using the Windows layout. Calibration changes apply directly; Cancel restores original brightness.
- Friendly names, light/dark themes, per-monitor DPI, and a direction-aware rotating icon with a soft 120-degree stop.
- Per-user installer with optional startup/desktop shortcuts, plus a portable ZIP. No separate Visual C++ runtime required.

## Downloads

- **BrightnessTray-0.1.0-Setup-x64.exe** — installer and uninstaller.
- **BrightnessTray-0.1.0-Portable-x64.zip** — extract and run.
- **SHA256SUMS.txt** — SHA-256 checksums.

Enable DDC/CI in the monitor menu. Use Exit before installing or upgrading. Preferences and calibration are preserved. Binaries are unsigned.

Integer hardware steps and slow DDC/CI calls remain visible on some displays. Continuous transitions and simultaneous physical changes are not guaranteed. Visual matching does not replace a colorimeter. HDR and GPU gamma are not modified.
